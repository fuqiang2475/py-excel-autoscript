# daily_report 模块说明
## 功能概述
化工日报表自动化处理核心模块，针对化工企业倒班人员填报场景，实现从Word交接班记录中提取白班/夜班生产数据，自动填充至Excel报表并完成公式更新、月度工作表创建等操作，内置数据校验与容错机制，匹配非连续生产的报表处理逻辑。

## 核心组件
1. **core.py**：主处理逻辑，调度数据解析、Excel操作、数据校验的全流程
2. **parser.py**：Word文档解析器，提取交接班记录中的结构化生产数据
3. **excel_ops.py**：Excel操作模块，实现数据填充、公式更新、月度工作表自动创建
4. **static.py**：静态数据验证规则，校验数据格式与范围（如介质消耗数值边界、罐区液位百分比范围）

## 关键特性
1. 支持白班/夜班分段数据的提取与填充，适配非连续生产报表逻辑
2. 内置文件存在性检测、数据覆盖确认、错误信息提示等容错机制
3. 每月2日自动创建新的月度工作表，满足长期数据统计需求
