# 化工连续生产日报表数据生成器

## 项目简介

这是一个用于生成化工连续生产日报表数据的Python脚本，模拟了31天完整生产数据、1个白班和1个夜班的数据。数据按照化工行业实际生产逻辑生成，考虑了原料投入、产品产出、介质消耗、能耗、三废排放、罐区液位等多个维度的数据，并提供了合理的精度设置。

## 功能特性

1. **完整数据周期**：生成31天完整日报表数据 + 2个分班数据（白班/夜班）
2. **多维度数据生成**：
   - 原料投入与产品产出
   - 介质消耗（腐蚀性/有毒性介质）
   - 能耗数据（蒸汽、水、电、气）
   - 三废排放数据（雨水、废液、废渣）
   - 辅料消耗数据
   - 罐区液位与库存数据
   - 流量计累计读数
3. **合理精度设计**：根据用量大小自动确定数据精度（吨、千克、立方米等）
4. **真实业务逻辑**：
   - 根据转化率计算产品产出
   - 罐区液位与实际用量关联
   - 补货逻辑（液位低于阈值时自动补货）
   - 分班数据减半处理

## 数据结构

脚本生成的数据包含以下字段：

### 基本信息
- `日期时间`：交班时间（格式：YYYY-MM-DD HH:MM）
- `班次`：全天/白班/夜班

### 生产数据
- `生产A批数`、`生产B批数`：当日生产的批次数量
- `原料A总消耗_吨`：原料A总用量
- `原料A（生产产品A用）_吨`、`原料A（生产产品B用）_吨`：按产品分类的原料用量
- `产品A_吨`、`产品B_吨`：产品A和B的产量

### 介质与辅料
- `腐蚀性介质_吨`、`有毒性介质_吨`：介质消耗量
- `产品A辅料_kg`、`产品B辅料_kg`：辅料消耗量

### 能耗数据
- `总热源_吨`、`废液B处理热源_吨`：蒸汽消耗
- `工艺水B_吨`、`工艺水A_吨`：工艺水消耗
- `电量_kWh`、`动力风_Nm³`、`保护气_Nm³`：电力和气体消耗

### 三废数据
- `雨水_吨`、`废液A转移量_吨`、`废液B排放_吨`、`废渣_吨`

### 罐区数据
- `有毒性二号罐液位_%`、`有毒性三号罐液位_%`
- `腐蚀性一号罐液位_%`、`腐蚀性二号罐液位_%`
- `有毒性二号罐库存_吨`、`有毒性三号罐库存_吨`
- `腐蚀性一号罐库存_吨`、`腐蚀性二号罐库存_吨`
- `有毒卸车`、`腐蚀卸车`：卸车补货量

### 流量计读数
- `原料A使用流量_吨`、`热源流量计_吨`
- `工艺水B流量计_吨`、`工艺水A流量计_吨`
- `电表读数_kWh`、`动力风流量计_Nm³`、`保护气流量计_Nm³`
- `废液A累积流量计_吨`


```bash
pip install pandas numpy openpyxl
```

```bash
python data_produce.py
```

### 输出文件
运行后会生成 `化工日报表数据.xlsx` 文件，包含以下工作表：
1. **全部数据**：所有记录的转置视图（每列为一个记录）
2. **完整日数据**：31天完整数据的转置视图
3. **2月2日白班**：白班数据的转置视图
4. **2月2日夜班**：夜班数据的转置视图

## 配置说明

在 `DailyReportGenerator` 类的 `__init__` 方法中可修改以下配置参数：

```python
self.config = {
    'raw_A_to_A_atomic': 0.9,      # 原料A到产品A的转化系数
    'raw_A_to_B_atomic': 1.1,      # 原料A到产品B的转化系数
    'raw_A_variation': 0.02,       # 原料用量波动范围
    
    'conv_A_min': 0.88,            # 产品A转化率最小值
    'conv_A_max': 0.92,            # 产品A转化率最大值
    'conv_B_min': 0.78,            # 产品B转化率最小值
    'conv_B_max': 0.82,            # 产品B转化率最大值
    
    'catalyst_ratio': 1.07,        # 催化剂比例
    'additive_ratio': 0.7,         # 添加剂比例
    'steam_ratio': 0.8,            # 蒸汽比例
    'waterB_ratio': 0.5,           # 工艺水B比例
    'waterA_ratio': 0.7,           # 工艺水A比例
    'power_ratio': 45,             # 电耗比例
    'air_ratio': 200,              # 动力风比例
    'gas_ratio': 50,               # 保护气比例
}
```

## 数据精度说明

根据实际用量大小，数据采用不同的精度：
- **原料、产品、蒸汽**：保留1位小数（吨）
- **介质消耗**：保留2位小数（吨）
- **辅料**：整数（千克）
- **能耗**：电、气等为整数
- **罐区液位**：保留2位小数（%）
- **流量计读数**：根据累计值大小确定精度

## 注意事项

1. **时间逻辑**：日期时间表示交班时间，数据为该班次期间的数据
2. **罐区液位**：液位数据是班次结束时的值，初始液位有预设值
3. **流量计读数**：为累计值，基于预设的起始值逐步累加
4. **数据随机性**：使用固定随机种子（seed=42）确保结果可复现
5. **分班数据**：白班和夜班数据按半天用量计算，并有轻微波动

## 扩展与定制

1. 修改 `self.full_days` 可调整生成的天数
2. 调整 `self.config` 中的比例参数可改变数据规模
3. 可添加新的数据字段或修改现有生成逻辑
4. 输出格式可根据需要调整（如添加原始非转置视图）
