# 化工日报表处理系统

## 项目简介

本项目是为化工企业倒班人员设计的日报表自动化处理工具。针对下夜班时需要在紧张的交班时间内完成日报表制作的痛点，本程序旨在减轻重复劳动、减少人工失误。

### 背景与痛点
- **时间紧张**：倒班人员下夜班时需要在有限的交班时间内完成报表制作
- **重复劳动**：每日需要修改昨日报表公式，并从两个班次生产记录中手工摘录关键数据，流程固定且繁琐
- **易出错误**：人工抄写易产生数据错误，公式更新可能遗漏
- **月度工作**：每月2日还需新建月度表单，增加额外工作量

### 解决方案
本程序自动化处理上述所有繁琐步骤：
- **一键操作**：填写报表信息后，只需双击`run.bat`即可自动完成所有处理
- **智能防误**：检测到今日报表已存在时，会提示用户确认是否覆盖，避免误操作
- **自动解析**：从Word格式的交接班记录中提取生产数据
- **智能更新**：自动更新Excel报表公式并填充数据
- **月度维护**：每月2日自动创建新的月度工作表
- **防错设计**：减少人工干预，降低抄写和公式错误风险

### 使用简便性
1. **一键启动**：完成报表信息填写后，双击`run.bat`即可启动整个处理流程
2. **智能保护**：当检测到今日报表已存在时，程序会弹出确认提示，避免意外覆盖重要文件
3. **操作简单**：无需复杂配置，普通员工也能轻松使用

### 效率提升
本程序将原本每日固定需要**5-10分钟**的重复性手工操作自动化，让倒班人员能够：
- 减少机械性数据录入工作
- 避免公式更新遗漏
- 更专注于数据核对和异常判断

### 应用场景
本程序模拟的是一个**非连续生产的化工装置**，使用原料A生产两种产品：
- **产品A**：通过特定工艺路线生产
- **产品B**：通过另一工艺路线生产

每日生产记录包含原料消耗、产品产出、介质使用、能耗数据、罐区液位等关键信息。

> **注**：本程序中使用的所有表格和数据均已脱敏处理，不包含任何实际生产信息。

## 系统价值
- **减轻负担**：减少每日5-10分钟的重复性手工劳动
- **操作简便**：一键启动，无需复杂操作
- **安全性高**：防止误覆盖现有文件，数据安全有保障
- **准确性保证**：自动化处理减少人为抄写错误
- **标准化作业**：确保每日报表格式和数据一致性
- **防错设计**：避免公式更新遗漏和数据录入错误

通过本辅助工具，倒班人员可以更准确、更规范地完成日报表制作，在紧张的交接班时间内更好地完成工作交接，同时减少因重复性工作带来的疲劳感。

## 快速开始

### 常规使用（正常模式）
1. **获取生产记录**：
   - 从工作群聊中找到当日的白班和夜班生产记录消息
   - 将两条记录内容分别复制粘贴到"报表信息.docx"中（粘贴顺序无关）

2. 将昨日报表文件放入程序目录

3. **双击`run.bat`**启动处理

4. 如需重新生成，按提示确认覆盖即可

---

### 演示模式（已开启调试）
*为了方便演示和学习，本程序已预设为调试模式，可以模拟特定日期的运行效果*

1. **模拟获取生产记录**：
   - 打开"2月1日白班生产记录.txt"，复制内容到"报表信息.docx"
   - 打开"2月1日夜班生产记录.txt"，复制内容到"报表信息.docx"

2. 将"某某装置日报表(2025-1-31).xlsx"放入程序目录（作为昨日报表）

3. **双击`run.bat`**启动处理
   - 程序将模拟生成2025年2月1日的日报表
   - 输出文件："某某装置日报表(2025-2-1).xlsx"

4. 如需重新生成，按提示确认覆盖即可

## 功能特性

### 1. 自动化处理
- **日期智能识别**：自动识别当前日期，生成对应的文件名
- **数据解析**：从Word文档中提取生产、能耗、库存等数据
- **Excel自动更新**：将数据填充到指定Excel模板的对应位置
- **公式自动调整**：自动调整Excel中的公式引用

### 2. 月度智能维护
- **月度表格创建**：每月2日自动创建新的月度工作表
- **年累计更新**：自动更新年累计公式
- **数据搬运**：自动搬运上月数据到相应位置

### 3. 容错处理
- **文件检查**：自动检查输入文件是否存在
- **格式验证**：验证数据格式和范围
- **错误捕获**：详细的错误信息提示
- **备份机制**：复制昨日报表作为今日模板

### 4. 灵活运行模式
- **普通模式**：双击运行，交互式操作
- **调试模式**：通过DEBUG.txt文件指定运行日期

## 安装与配置

### 环境要求
- Python 3.7+
- Windows 7/10/11（推荐）

### 安装步骤

1. **安装Python**
   - 从[Python官网](https://www.python.org/)下载并安装Python 3.7+
   - 安装时勾选"Add Python to PATH"

2. **获取项目文件**
   - 下载或克隆本项目到本地目录

3. **运行初始设置**
   ```bash
   # 双击 run.bat
   # 或命令行执行
   python run.py
   ```

### 依赖安装
系统会自动安装以下依赖：
- `python-docx`：用于读取Word文档
- `openpyxl`：用于操作Excel文件

## 使用方法

### 准备工作

1. **文件命名规范**
   - Excel日报表命名：`某某装置日报表(YYYY-M-D).xlsx`
   - 例如：`A装置日报表(2025-12-1).xlsx`

2. **输入文件准备**
   - 将昨日报表文件（Excel）放在程序目录中
   - 将当日报表信息复制到`报表信息.docx`中

### 日常使用流程

1. **准备数据**
   - 复制昨日的Excel日报表到程序目录
   - 打开`报表信息.docx`，粘贴当日报表信息

2. **运行程序**
   - 双击`run.bat`（推荐）
   - 或命令行执行：`python run.py`

3. **查看结果**
   - 程序会自动生成今日的日报表文件
   - 文件名格式：`某某装置日报表(YYYY-M-D).xlsx`
   - 数据已自动填充，部分需要手动确认

### 运行模式

#### 常规模式
直接运行程序，系统：
1. 自动识别当前日期
2. 查找昨日报表文件
3. 解析`报表信息.docx`
4. 生成并更新今日报表

#### 调试模式
创建`DEBUG.txt`文件，内容可以是：
- 空文件：运行今日数据
- 指定日期：按指定日期运行（格式：YYYY-MM-DD）

示例：
```txt
# DEBUG.txt 内容
2025-12-10
```

## 文件格式要求

### 1. 报表信息.docx 格式
Word文档应包含以下信息结构：

```txt
工艺水A：123.4
工艺水B：567.8
...
腐蚀性库存：89.0
...
有毒性一号罐液位：45.6
有毒性二号罐液位：67.8
...
24小时腐蚀性供料槽总液位：1234.5
```

### 2. Excel模板结构
Excel日报表应包含以下工作表：
- 当前月份工作表（如"12月"）
- 包含以下数据区域：
  - 昨日消耗数据（H列到AO列）
  - 今日统计数据（AQ列到BW列）
  - 库存信息区域
  - 年累计统计区域

## 关键功能详解

### 1. 月度自动维护
- **触发时间**：每月2日自动执行
- **执行内容**：
  - 创建新月份的工作表
  - 搬运上月数据
  - 清空无效数据区域
  - 更新日期列
  - 调整年累计公式

### 2. 数据自动填充
系统自动填充以下数据：

#### 昨日消耗数据
- 腐蚀性介质使用情况
- 有毒性介质使用情况
- 废液A转移量
- 废液B排放量
- 废液B处理热源量

#### 今日统计数据
- 罐体液位信息（有毒性、腐蚀性）
- 原料A用量数据
- 各类流量计读数
- 库存吨位计算

### 3. 公式自动调整
- **昨日消耗公式**：自动拖动到对应日期列
- **今日统计公式**：自动填充和调整
- **年累计公式**：自动添加新月份引用

## 错误处理

### 常见问题及解决方法

1. **找不到昨日报表文件**
   - 检查文件名是否符合命名规范
   - 确认文件是否在程序目录中

2. **Word文档解析失败**
   - 检查`报表信息.docx`格式是否正确
   - 确认内容是否完整

3. **Excel操作失败**
   - 确认Excel文件未被其他程序占用
   - 检查Excel文件格式是否正确

4. **数据验证失败**
   - 检查输入数据范围是否合理
   - 确认数值格式是否正确

### 调试模式
遇到问题时，可以：
1. 创建`DEBUG.txt`文件
2. 运行程序查看详细错误信息
3. 根据提示修复问题
