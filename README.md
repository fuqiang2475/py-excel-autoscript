# 化工日报表半自动化工具

## 项目简介
专为非连续生产化工装置的倒班人员定制开发的自动化工具，聚焦交接班时报表制作的核心痛点：
- 时间紧张：下夜班后需在有限时间内完成报表填报
- 重复劳动：每日需手动摘录双班次生产数据、更新报表公式
- 易出错误：人工抄写数据、调整公式易遗漏或出错
- 额外负担：每月2日需手动新建月度工作表并维护数据

本工具通过自动化处理上述繁琐流程，减少重复劳动与人为失误，帮助倒班人员高效完成报表制作。

## 核心功能
1. 数据自动解析：从Word格式（.docx）交接班记录中提取原料消耗、产品产出、介质使用、罐区液位等结构化生产数据
2. Excel报表处理：自动填充数据至指定Excel模板，同步更新昨日消耗、今日统计、年累计等相关计算公式
3. 月度智能维护：每月2日自动创建新月度工作表，完成上月数据搬运与公式适配
4. 容错与防误设计：检测输入文件存在性、验证数据格式与范围，覆盖现有报表时触发确认提示
5. 双运行模式：支持常规交互模式与指定日期的调试模式（通过DEBUG.txt配置）
6. 人工补填提示：因部分现场专属数据无法通过交接班记录自动获取，程序生成报表后需人工接管完成剩余数据填写与最终确认

## 定制化适用场景（固定适配）
- 生产模式：非连续生产的化工装置
- 数据维度：需区分白班/夜班的生产记录统计（原料A消耗、产品A/B产出、介质使用、能耗、罐区液位等）
- 报表需求：每日固定格式Excel报表填报，每月需新建月度工作表并维护年累计数据
- 使用者：化工企业倒班人员（交接班时间紧张，需快速完成报表制作）

## 快速开始
### 环境要求
- Python 3.7+
- Windows 7/10/11 系统
- 依赖库：python-docx（读取Word）、openpyxl（操作Excel）

### 安装步骤
1. 下载或克隆本项目至本地目录
2. 安装Python并勾选"Add Python to PATH"
3. 双击 `run.bat` 自动安装依赖并启动程序（或命令行执行 `python run.py`）

### 使用流程
1. 准备文件：将昨日报表（Excel格式，命名规范：`某某装置日报表(YYYY-M-D).xlsx`）放入程序目录；将白班/夜班生产记录复制到 `报表信息.docx`（键值对格式，例：`工艺水A：123.4`）
2. 启动程序：双击 `run.bat`，按提示完成操作
3. 完善报表：程序自动生成当日报表（同格式命名），已填充解析数据并更新公式；需结合现场实际情况，手动补填非标准化数据并确认无误

### 调试模式
1. 在程序目录创建 `DEBUG.txt` 文件
2. 空文件则按当日日期运行；填写日期（格式：YYYY-MM-DD）可指定运行日期

## 模块结构
```
├── run.py              # 主程序入口（调度执行流程）
├── run.bat             # Windows启动脚本（简化启动操作）
├── daily_report/       # 核心功能模块
│   ├── core.py         # 核心逻辑控制（协调解析、Excel操作、校验流程）
│   ├── parser.py       # 数据解析模块（读取Word文档并提取结构化生产数据）
│   ├── excel_ops.py    # Excel操作模块（数据填充、公式调整、工作表创建）
│   └── static.py       # 静态配置模块（数据验证规则、固定格式定义）
├── requirements.txt    # 依赖包清单（管理第三方库版本）
└── 报表信息.docx       # 输入数据模板（用户填写生产记录的载体）
```

## 文件格式要求
- Word输入文件（报表信息.docx）：需严格遵循"键：值"格式填写生产数据，确保结构化可解析
- Excel模板：需包含当前月度工作表，划分昨日消耗（H-AO列）、今日统计（AQ-BW列）、库存及年累计统计区域，格式不可随意修改

## 常见问题与处理
1. 找不到昨日报表文件：检查文件名是否符合规范、文件是否在程序目录
2. Word文档解析失败：确认`报表信息.docx`格式正确、内容完整
3. Excel操作失败：关闭占用目标Excel文件的程序，检查文件格式是否为.xlsx
4. 数据验证失败：核对输入数据的范围与数值格式是否合理

## 注意事项
1. 仅支持.xlsx格式Excel与.docx格式Word文件，需严格遵循命名规范与模板结构
2. 运行时请勿打开目标Excel文件，避免文件占用导致操作失败
3. 建议首次使用时用测试数据验证功能，重要文件提前备份
4. 工具为特定场景定制，未适配其他生产模式或报表格式的通用需求
